# 工作日历pro

让每一段时间，都有价值。Every hour counts.

一个无需安装、直接在浏览器运行的日历与收入记录工具。

## 使用

双击 `index.html`，或使用任意静态文件服务器打开。数据保存在当前浏览器的 `localStorage` 中。

## 部署与数据

当前版本是纯前端本地应用，部署到静态网站即可访问，例如 GitHub Pages、Cloudflare Pages、Vercel 或 Netlify。直接部署后，数据仍只保存在每台设备各自浏览器的 `localStorage` 中，优点是简单且隐私风险低，缺点是不能自动跨设备同步。

如果要真正跨平台同步，建议加后端与登录系统。比较合适的方案是 Supabase 或 Firebase：日程、标签、客户和收入记录存到云端数据库，按用户账号隔离，并开启行级权限。涉及收入、客户和日程隐私时，应使用 HTTPS、登录鉴权、数据库权限规则和定期备份；不要把数据写进公开仓库，也不要把数据库密钥放进前端代码。

## 功能

- 月视图、周视图与快速切换
- 月视图双击任意日期，可直接进入该日期所在的周视图
- 月视图与周视图的日期标题都可点击，通过自定义月历直接定位到目标日期
- 按月或按周前后翻页
- 周视图底部提供“上一周 / 下一周”按键，也可在日历内使用 `Shift + 滚轮`
- 周视图按 0:00–24:00 时间轴展示日程位置与时长，坐标轴使用整点刻度
- 可从日历工具栏进入“输出周表”，并切换周表或月表、日历视图或列表视图
- 客户安排表可选择单个客户或全部客户；月表会按周纵向排列每周安排
- 客户表隐藏收入和备注；空闲档期会合并已占用时段，线下日程前后各预留 30 分钟赶路时间，两种版本都仅输出 08:00–22:00
- 输出表可复制为纯文字，也可打印或保存为 PDF
- 点击周视图空白时间会先生成 30 分钟草稿卡片，并在右侧栏编辑
- 未修改草稿时再次点击周视图其他空白处，会撤销这条草稿，并保持页面与时间轴位置
- 周视图长按空白区域后拖动，可直接拉出任意长度的新日程
- 从周视图点击新建时会保留页面和时间轴滚动位置
- 编辑表单固定在侧边栏，操作时日历始终可见
- 新草稿只有在字段、时间或时长发生修改后才会自动保存
- 未做任何修改便关闭时不会产生记录
- 拖动日程可改日期与开始时间
- 月视图也可将日程拖到其他日期
- 拖动日程卡片底部可调整时长，操作按 15 分钟吸附
- 同一天内时间重叠的日程会依次向右缩进叠放，保留卡片宽度
- 可创建带名称和颜色的标签，使用 24 色预设色板或自定义颜色盘并保存在浏览器中
- 单条日程可以同时选择多个标签；标签栏会用对应颜色显示全部已选标签，未选择时只显示“无标签”
- 在标签菜单中右键标签，可修改名称、颜色或删除标签
- 客户作为可复用资料管理，可新建、选择、右键修改或删除
- 日程支持同时输入开始时间、结束时间和时长，三者自动联动
- 日程可标记为线上或线下工作方式
- 日程支持每天、每周、每月、每年及自定义间隔重复
- 自定义重复可关闭固定频率，改用侧栏日历多选指定日期，或手动输入完整/短日期
- 日程支持右键复制与指定位置粘贴，也支持 `Ctrl+C`、`Ctrl+V`；复制后点击空白位置即可粘贴
- 顶部收入、有收入日程数和工时均使用放大的标签占比环图，并显示主要标签与占比说明
- 顶部收入卡同时展示本月实际收入、自定义目标、完成比例与进度条，目标按月份分别保存
- 抽屉菜单提供“其他收入”列表，可记录投资收入、补助、奖学金、生活费等不进入日历的收入
- 其他收入支持日期、金额、备注与多标签，也可在编辑时直接新建彩色标签；收入会计入实际收入、月/年收入和标签收入构成，但不计入工时
- 主页日历下方同步展示当前选中月份的其他收入，并按标签汇总；点击某个标签汇总可进入该年月和标签的明细列表
- 其他收入页可按年份和月份筛选，并显示对应期间的笔数与合计
- 顶部概览可以收起；点击任一概览卡片可进入对应统计板块
- 概览栏下方使用独立的上下箭头控制展开和收起
- “本月有收入日程”只统计收入大于 0 的日程，单位为“个”
- 跨月周按照当前选中日期归属的月份统计
- 支持智能录入日期、日期范围、时间点、时间段、收入、客户、标签和线上/线下；日期、时间和收入为必填项，`9.1 9.2` 可批量创建多天，`9.1-9.3` 可创建包含首尾的连续日期
- 提供类似 GitHub Contribution Graph 的所选年份每日工时图
- 年度时间贡献图标题会显示所选年份，并可按某一个标签或“无标签”筛选
- 左上角抽屉菜单集中提供日历、统计、其他收入、“标签与客户”和回收站；标签与客户在同一页面分区管理
- 统计页提供月收入、年收入、月/年工时、标签构成与年度时间价值足迹
- 删除的日程会先进入回收站，可恢复或二次确认后彻底删除
- 选中日程后可按 `Delete` 移入回收站，也可在日程右键菜单中选择删除
- 删除确认使用侧栏内的小气泡，不遮罩页面
- 收入数字输入框每次按箭头增减 100 元
- 新建、编辑、删除日程
- 记录课时时长、客户与收入
- 客户名称会直接显示在月视图、周视图和当日列表的日程卡片中
- 有收入的日程会在月视图、周视图和当日列表中显示醒目的价格徽标
- 本月收入、日程数和总工时统计
- 统一中英文字体与更轻盈的卡片式视觉设计
- 原生选择框与自定义下拉栏使用统一字体、间距和箭头样式
- 开始时间、结束时间和重复选项改为与标签、客户一致的自定义选择面板
- 手动切换到“自定义重复”时，不会默认开启按固定频率重复
- 统计页的年度足迹严格按所选年份过滤，不再混入其他年份数据
- 桌面端与移动端自适应
